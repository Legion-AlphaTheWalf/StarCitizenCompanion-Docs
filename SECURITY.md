# Reporting a security issue

[Back to the docs](README.md)

Report vulnerabilities, exposed credentials and private-account/data concerns directly to **AlphaTheWalf** in Discord or [AlphaTheWalf@gmail.com](mailto:AlphaTheWalf@gmail.com).

Keep tokens, passwords, OAuth credentials, private server records, personal identifiers, unredacted logs and exploit details out of public GitHub issues. Send a short description privately first, then arrange a safe way to share any sensitive evidence. SCC will not ask for your Discord, Citizen iD or RSI password.

For ordinary reproducible bugs, use `/bug` or the [public issue form](https://github.com/Legion-AlphaTheWalf/StarCitizenCompanion-Docs/issues/new/choose). Bot reports go to the owner for review and aren't automatically posted publicly. See [privacy](PRIVACY_POLICY.md).
