# Reporting a security issue

[Back to the docs](README.md)

If you find a vulnerability, exposed credentials, or a private account/data issue, contact me (**AlphaTheWalf**) in Discord or [by email](mailto:AlphaTheWalf@gmail.com).

Keep tokens, passwords, OAuth credentials, private server records, personal identifiers, unredacted logs and exploit details out of public GitHub issues. Send me a short description privately first, and we can arrange a safe way to share any sensitive evidence. I won't ask for your Discord, Citizen iD or RSI password.

For ordinary reproducible bugs, use `/bug` or the [public issue form](https://github.com/Legion-AlphaTheWalf/StarCitizenCompanion-Docs/issues/new/choose). I review bot reports privately; they aren't automatically posted publicly. See [privacy](PRIVACY_POLICY.md).
